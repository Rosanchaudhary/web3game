# 🎮 BetGames — Play, Win & Earn ETH

BetGames is a decentralized gaming hub built with **Next.js 13+**, where players can enjoy classic arcade-style games like **Memory**, **Tetris**, **Snake**, **Flappy Bird**, and **Mario Platformer** — and **earn Ether (ETH)** as rewards for their performance.

Powered by **Web3**, **Next.js**, and **Framer Motion**, BetGames brings nostalgic fun with blockchain integration.
